
# ДеньгиGO — Telegram-бот

## Что умеет первая версия
- Главное меню.
- Категории: «Заработать», «Быстро», «Бонусы», «Онлайн-подработка».
- Раздел «Продать вещи».
- Реферальная ссылка на самого бота.
- Счётчик приглашённых пользователей.
- SQLite-база.
- Админ-команды `/add` и `/offers`.

## Установка

1. Установи Python 3.11+.
2. Создай бота через @BotFather командой `/newbot`.
3. Скопируй токен в переменную `BOT_TOKEN`.
4. Узнай свой Telegram numeric ID и укажи его в `ADMIN_ID`.
5. Выполни:
   `pip install -r requirements.txt`
6. Запусти:
   `python bot.py`

## Добавление предложения

Администратор отправляет боту:

`/add bonus | Название | Описание предложения | до 1000 ₽ | 5 минут | https://example.com`

Категории:
- `fast`
- `bonus`
- `online`

## Важно про банковские предложения

Не вставляй реферальные ссылки, пока не проверены действующие правила конкретной программы.
Не обещай пользователю гарантированную выплату.
Явно сообщай, если ссылка является партнёрской и ты можешь получить вознаграждение.

Для автора младше 18 лет особенно важно проверить возрастные требования и правила выплат. Не обходи ограничения через чужие данные или аккаунты.
